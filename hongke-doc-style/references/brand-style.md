| 深橙 | `#D87718` | H1标题文字、报废/异常类分支框、强调文字 |

| 中灰 | `#595959` | 副标题、说明文字、箭头 |
| 浅橙底纹 | `#FDF3E3` | 表格隔行底纹 |
| 边框灰 | `#E5E7EB` | 表格边框 |

## 字体

- docx：`ascii/hAnsi: Arial`，`eastAsia: Microsoft YaHei`
- 流程图（matplotlib）：环境中文字体已预配置，不要修改 rcParams 的字体设置

## docx 样式约定

- H1：深橙 `#D87718` 加粗，底部橙色分隔线；H2：深灰加粗
- 表格：表头主橙底白字加粗居中，数据行隔行浅橙底纹，列宽用 DXA 且总和不超过 9026（A4 正文可用宽）
- 页眉：文档标题 + 橙色底部分隔线；页脚：居中页码
- 版本信息表（首页）：版本号/审核周期/编制部门/涉及部门/编制审核批准/生效日期，签署位留"（按实际签署）"
- 正式文档含目录（TOC域 + 缓存条目，`updateFields: true`）

## 流程图规范

- 白色背景（`facecolor='white'`，不要用透明底），450dpi
- 框内**无填充色**：白底 + 彩色圆角边框（lw≈1.8）+ 彩色文字
- 框内三行结构：标题（彩色加粗）/ 说明（中灰）/ **责任人（彩色加粗，必标）**
- 主流程框用主橙；质量判定类用浅金系；终审/关单类用深灰；报废/回退分支用深橙
- 箭头：中灰直线，回退/循环箭头用深橙弧线
- 平衡公式等关键结论：框外纯文字，深灰加粗
- 交付前必须打开图片自检：文字不溢出框、元素不重叠

### PPT 构建技术规范

> 经验来源：2026-10-12 ED57C 节气门安装匹配说明书交付，从零重建法验证通过。

**禁止直接在 WPS 源文件上二次编辑**
- WPS 生成的 .pptx 经 python-pptx 读写后，部分 OOXML 节点位置/格式不标准，PowerPoint / WPS 高版本无法打开（预览空白、下载打不开）。
- **正确做法**：用 python-pptx 标准模板（`slide_layouts[6]` 空白版式）从零构建，背景图以 `shapes.add_picture` 方式铺满整页，不依赖母版。

**照片素材预处理**
1. **iPhone MPO → JPEG**：python-pptx 不认 MPO 格式，必须先用 Pillow 转成 JPEG。
2. **尺寸压缩**：iPhone 原图通常 4K 以上，单张 5–8MB。用 Pillow 缩放到最长边 1600px（quality 82）后，整份 PPT 可从 16MB+ 压到 1.5MB 左右，PPT 放映清晰度完全足够。
3. **比例统一**：竖版照片（3:4）和横版照片（4:3）分别计算等比尺寸，避免变形。

**字体节点 OOXML 位置**
- python-pptx 默认不写入 `<a:ea>` 东亚字体节点，必须手动插入到 run 的 rPr 中：
  - `<a:latin typeface="黑体"/>` 放在 rPr 第 0 位；
  - `<a:ea typeface="黑体"/>` 紧跟 latin 之后（`latin.addnext(ea)`）。
- 这是避免 WPS/PowerPoint 回退到默认字体的关键。

**章节页结构常量（可直接复用）**
```python
# 橙色序号方块
add_shape(RECTANGLE, left=301248, top=161426, width=1139824, height=523220, fill=#E78F13)
# 序号文字：白 28pt 黑体，居中
# 章节标题：橙 #E2931E，32pt 黑体，x≈1615440
# 分隔细条：x=301248, y=800000, 宽 11589504, 高 28000, fill=#EAB46B
```

**内容页排版惯例**
- 文字区：左侧或上方，x≈301248 EMU（约 0.42cm 页边距），正文 18pt，小标题 20pt 橙色加粗。
- 照片区：右侧或下方，等比缩放，底部留 60000 EMU 放居中灰色图注（13pt）。
- 提示/注意框：右侧浅橙底 `#FBEEED` + 橙色边框 `#E2931E` 1.25pt，内边距约 0.6cm。

注意：PPT 橙色系（标题 `#E2931E` / 序号块 `#E78F13`）与 docx 主橙 `#E78F13`、深橙 `#D87718` 同源不同值，分别来自《ED57C安装说明书.pptx》和《鸿科风格.pptx》两个源文件——按交付物类型各用各的，不要混用。
