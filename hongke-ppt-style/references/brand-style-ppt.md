# 鸿科 PPT 品牌样式规范

来源：《ED57C安装说明书.pptx》解析提取，2026-10-13 经完整交付验证；2026-10-18 新增"流程图原生形状"强制规范。**若用户另提供鸿科 PPT 源文件，以新文件解析值为准，不要套用 docx 配色。**

| 角色 | 色值 | 用途 |
|------|------|------|
| 标题橙 | `#E2931E` | 章节页标题、强调 |
| 序号块橙 | `#E78F13` | 橙色序号方块、表头底色、小标题 |
| 分隔细条 | `#EAB46B` | 页眉下分隔条 |
| 正文深灰 | `#404040` | 正文标题、表格主文字 |
| 副标题中灰 | `#595959` | 副标题、说明文字、图注 |
| 隔行底纹 | `#FDF3E3` | 表格隔行 |
| 提示框底 | `#FBEEDC` | 注意/警告框底色（配标题橙边框） |
| 边框灰 | `#E5E7EB` | 表格边框 |
| 背景 | 纯白 `#FFFFFF` | 所有页面 |

注意：PPT 橙系（标题 `#E2931E` / 序号块 `#E78F13`）与 docx 主橙 `#E78F13`、深橙 `#D87718` 同源不同值，分别来自《ED57C安装说明书.pptx》和《鸿科风格.pptx》两个源文件——按交付物类型各用各的，不要混用。

## 字体

- 全文黑体；每个 run 的 rPr 必须同时写入 `<a:latin typeface="黑体"/>`（rPr 第 0 位）和 `<a:ea typeface="黑体"/>`（紧跟 latin 之后），否则 WPS/PowerPoint 回退默认字体
- 常用字号：封面主标题 48pt（或按品牌基准 54pt，超长标题两行 48pt）、副标题 20pt、章节标题 32pt、序号 28pt、正文 18pt、小标题 20pt 加粗、表格 15–16pt、图注 13pt

## PPT 构建技术规范

> 经验来源：2026-10-12 ED57C 节气门安装匹配说明书交付（从零重建法）、2026-10-18 客户版测试结果说明交付（原生形状流程图 + 表格）。

**禁止直接在 WPS 源文件上二次编辑**
- WPS 生成的 .pptx 经 python-pptx 读写后，部分 OOXML 节点位置/格式不标准，PowerPoint / WPS 高版本无法打开（预览空白、下载打不开）。
- **正确做法**：用 python-pptx 标准模板（`slide_layouts[6]` 空白版式）从零构建，背景图以 `shapes.add_picture` 方式铺满整页，不依赖母版。

**表格**
- 用 `shapes.add_table`，样式设为 "No Style, Table Grid"（tableStyleId `{5940675A-B579-460E-94D1-54222C63F5DA}`），自填表头序号块橙底白字加粗、数据行白/浅橙隔行、边框 `#E5E7EB`（0.75pt）
- 禁止用零散文本框拼表格（客户无法整体编辑）

**照片素材预处理**
1. **iPhone MPO → JPEG**：python-pptx 不认 MPO 格式，必须先用 Pillow 转成 JPEG。
2. **尺寸压缩**：iPhone 原图通常 4K 以上，单张 5–8MB。用 Pillow 缩放到最长边 1600px（quality 82）后，整份 PPT 可从 16MB+ 压到 1.5MB 左右，PPT 放映清晰度完全足够。
3. **比例统一**：竖版照片（3:4）和横版照片（4:3）分别计算等比尺寸，避免变形。

**流程图：PPT 原生形状（2026-10-18 起为强制规范）**
- PPT 里的流程图**禁止贴 PNG**（PNG 版流程图属于 hongke-doc-style，仅用于 docx/SOP 文档）。用 `scripts/pptx_flowchart.py` + spec.json 生成，全部元素为原生可编辑对象：
  - 框 = ROUNDED_RECTANGLE（白底、彩色边框 1.8pt、圆角与 matplotlib 版一致），框内三行文字（标题彩色加粗 / 说明中灰 / 环节或责任人彩色加粗）为普通段落，可直接编辑
  - 直线箭头 = 连接线 + tailEnd 三角箭头（中灰，2.2pt）；回退/循环弧线 = 贝塞尔采样 freeform + 箭头（深橙），视觉与 matplotlib arc3 弧度一致
  - 备注（平衡公式等）= 框外文本框，深灰加粗
- 机理图（非业务流程）框内标系统环节（如"ECU 加浓修正"）；业务流程图框内标责任人（"责任人：xxx"）
- 用法：`python scripts/pptx_flowchart.py spec.json 输出.pptx`；输出文件已存在时追加一页到主文档。脚本自动生成 `输出.预览.png`，按预览自检文字溢出/重叠后交付

**内容页排版惯例**
- 文字区：左侧或上方，x≈301248 EMU（约 0.42cm 页边距），正文 18pt，小标题 20pt 序号块橙加粗。
- 表格区：左右分栏时右栏 x≈6.3M EMU；通栏表从 x=301248 起、宽 ≤11589504 EMU。
- 提示/注意框：浅橙底 `#FBEEDC` + 标题橙边框 1.25pt，内边距约 0.6cm。
